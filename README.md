# OP Pop-Up HUD

Photoshop 绘画快捷工具：拾色、笔刷、工具与命令，以及录制、导出和计时器。

**当前版本：2.0.1** · 可试用 7 天

[下载 2.0.1](https://github.com/xBADBRUSHx/OP-Pop-Up-HUD/releases/download/v2.0.1/OP-Pop-Up-HUD-Setup-2.0.1.exe) · [产品官网](https://badbrush.org/op-popup-hud/) · [更新说明](docs/release-notes-2.0.1.zh-CN.md)

## 安装

1. 保存作品，关闭 Photoshop，并登录 Adobe Creative Cloud。
2. 运行安装包，按提示完成安装或旧版迁移，无需先卸载或单独清理。
3. 在 Photoshop 的 **增效工具 → OP Pop-Up HUD → 设置** 中激活或领取试用。

已正常使用 2.0.1 的用户无需重装；此前安装失败的用户请下载当前安装包重试。

从 2.0 之前的版本升级会重置旧设置，作品与购买权益保留。正常 2.x 升级保留设置与授权。
