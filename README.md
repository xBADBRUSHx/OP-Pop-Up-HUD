## 安装与迁移 / Install and migrate

首次安装：保存作品，退出 Photoshop 和 HUD，双击 Setup。安装完成后，从 Photoshop **增效工具 → OP Pop-Up HUD → OP Pop-Up HUD · 设置** 打开，用邮箱和激活码激活，或领取 7 天试用。

用过 2.0.0 之前的 HUD：先退出 Photoshop 和 HUD，再完整解压 Cleaner ZIP，双击 `Start-Cleanup.cmd`，核对清单后输入 `CLEAN`；显示清理完成后再运行 Setup。旧配置会重置，购买权益、设备身份和作品保留。详见[清理工具说明](docs/Legacy-Cleanup.zh-CN.md)。

First install: save your work, close Photoshop and HUD, then run Setup normally. Open **Plugins → OP Pop-Up HUD → OP Pop-Up HUD · 设置** in Photoshop, then activate or start the 7-day trial.

Upgrading from a version before 2.0.0: close Photoshop and HUD, extract the entire Cleaner ZIP, run `Start-Cleanup.cmd` normally, review the list, and enter `CLEAN`. Run Setup after cleanup succeeds. Old settings reset; purchase rights, device identity, and artwork remain. Use your original email and activation code again. Normal 2.x updates retain settings and authorization.

## 支持 / Support

在 **设置 → 账户与帮助** 点击 **生成问题报告**；插件打不开时，可使用 Setup 中的报告入口或上面的独立 Report Tool。将生成的 ZIP 发到 **100209743@qq.com** 并说明问题。报告工具不会自动发送。

Create a report from **Account & Help (账户与帮助)**, Setup, or the standalone Report Tool. Send its ZIP and a short description to **100209743@qq.com**. The tool does not send reports automatically.
