# OP Pop-Up HUD 2.0.1

- 新增前后景色重置与调换命令；Alt + 左键重置，Shift + 左键调换。
- 修复安装、旧版升级和部分 Photoshop 原生图标问题。
- 安装失败时可直接生成问题报告，错误说明支持选中复制。

安装前请关闭 Photoshop，并登录 Adobe Creative Cloud。直接运行安装包，按提示完成安装或旧版迁移，无需先卸载或单独清理。

已正常使用 2.0.1 的用户无需重装；此前安装失败的用户请下载当前安装包重试。
