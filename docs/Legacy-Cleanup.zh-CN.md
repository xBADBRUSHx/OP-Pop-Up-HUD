# OP Pop-Up HUD 清理工具

**正常安装请直接运行新版 Setup。** 从 2.0.1 起，安装器已集成旧版迁移：检测到可识别的 2.0.0 之前版本后，按提示确认即可自动备份、清理并继续安装，通常无需单独运行本工具。

下方是历史独立 Cleaner 的手动维护说明，仅用于清理 **早于 2.0.0** 的 HUD，且只能在安装 2.0.0 或更高版本之前使用。发现新版或无法确认 HUD 身份时会停止，不执行清理。

1. 关闭所有 Photoshop、OP Pop-Up HUD 和 HUD 更新程序。
2. 将 ZIP **全部解压**，双击 `Start-Cleanup.cmd`。不要右键选择“以管理员身份运行”。
3. 查看清理清单，确认后输入大写 `CLEAN`，按回车。如弹出管理员权限提示，请允许，并保持使用当前 Windows 账户。
4. 显示“清理完成，按任意键退出”后，安装新版 HUD，再用原邮箱和原激活码激活。

不想继续：在输入 `CLEAN` 前关闭窗口即可。

显示“未完成”：按提示处理后重新运行。若提示文件身份无法确认，请将提示截图发给作者核实，暂勿安装新版。

## 说明

- 仅清理可确认早于 2.0.0 的 OP Pop-Up HUD 安装、旧设置和缓存；旧配置全部重置。保留设备身份 `license-device.dat` 和购买权益；需重新输入原邮箱和原激活码。用户作品、Photoshop 资源及其他产品不在清理范围内。发现作品或录制输出位于拟清理目录时会停止，避免误删。
- 清理范围为当前 Windows 用户和本机公共安装，不处理其他 Windows 用户的配置。
- 已安装 2.0.0 或更高版本时不要使用；工具会识别并拒绝清理。
- 早期 Photoshop 桥接文件没有 HUD 产品版本信息。工具会核对其内嵌的历史 HUD 资源；仅剩 handoff 时会核对旧版专属格式和目录内容。身份冲突或无法确认时会停止清理。
