# OP Pop-Up HUD 清理工具

新装和正常更新直接运行安装包。遇到旧桥接、多处旧版本残留，或需要移除旧安装再重装时，使用本工具清理一次。安装器不再自动执行旧版清理。

1. 关闭 Photoshop、OP Pop-Up 和更新程序。
2. 将 ZIP 全部解压，双击 `Start-Cleanup.cmd`。
3. 查看提示，输入 `CLEAN` 确认。通常会先列出清理项目；若上次数据恢复未完成，会在确认后先恢复数据，再检查清理项目。涉及系统安装时会请求管理员权限，请使用同一个 Windows 账户。
4. 完成后重新安装 OP Pop-Up。

默认移除 OP Pop-Up 各版本的程序、失败安装暂存、Photoshop 加载记录和 Windows 卸载登记，保留授权、设置、笔刷和录制作品。发现旧设备身份而没有当前格式时，会承接原身份，不产生新的激活设备。

- OK-Record 默认保留。明确需要同时移除其程序时，运行 `Start-Cleanup.cmd -IncludeOKRecord`；其个人数据仍保留。
- 需要重置设置时，运行 `Start-Cleanup.cmd -ResetSettings`。授权、作品、笔刷资产和设备身份仍保留。
- 如需清除本机授权，请在清理前使用插件“设置 → 账户帮助 → 管理授权”的清除入口；本工具不删除授权记录。
- 如果作品或额外文件放在程序安装目录中，会随整个目录归档，原路径不再保留。归档包含所有文件，不按扩展名筛选；普通用户数据目录保持原位。
- 清理前的备份保存在 `%LOCALAPPDATA%\BADBRUSH\HUD-Cleanup-Backups`。
- Adobe 服务不可用时仍可清理本地程序和加载记录，但会明确提示“Adobe 数据库注销未确认”。这不表示系统环境完全正常；Creative Cloud 恢复后应核对旧插件是否重新出现。
- 清理失败时保留备份，处理所列错误后可再次运行；如上次数据恢复未完成，会先接续恢复。已完成的旧备份不会覆盖现有数据。工具不直接改写 Adobe 数据库，不修改系统权限或其他插件的加载记录。
