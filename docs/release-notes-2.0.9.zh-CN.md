# OP Pop-Up HUD 2.0.9

## 新增

- 不透明度和笔刷角度支持独立的按住快捷键，默认未分配。可在 **设置 → 通用快捷键 → 笔刷参数调整** 中自行绑定。
- 按住自设快捷键，水平移动鼠标调不透明度，或垂直移动调角度；原来的 S、S＋右键、S＋左键操作保留。

## 改进

- OKLCH 色度滑条将当前明度、色相下不可用的范围显示为灰色，可选范围随颜色更新，色度刻度保持不变。

## 修复

- 修复快速切换笔刷调整快捷键时，后一个手势可能丢失的问题。
- 修复长按重复、界面取消和延迟读回时的按键归属，避免旧操作干扰下一次调整。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。正常更新保留设置、授权、笔刷与录制作品。
