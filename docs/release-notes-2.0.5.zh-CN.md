# OP Pop-Up HUD 2.0.5

- 新增色相增减快捷键：默认未分配，可自行绑定后按住 Q 使用；支持长按连续调整和独立角度步长，默认每次 1°。
- 新增快捷面板高亮颜色设置，统一调整 W／E／R／Z／F 槽位的悬停底色与选中描边。
- F 混合模式面板改为按下立即显示，取消短按切回“正常”；在中心松开时保持当前模式。
- 统一面板字体，改善中文标签、数值和计时显示的一致性。
- 工具栏的不透明度、流量、硬度和角度四个画笔参数圆可分别开关，关闭后不占位置。
- 计时器悬停提示随当前模式和运行状态变化。
- 修复工具栏清空后无法拖回工具、设置中添加槽位无效的问题；可重新拖入首个工具，或在设置中选择工具／命令后添加。
- 优化设置界面的分类、排版与编辑体验，完善恢复初始设置。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。直接运行新版安装包；仅当提示需要清理旧安装时，先运行配套的独立清理工具，再安装。
