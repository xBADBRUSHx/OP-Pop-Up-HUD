# OP Pop-Up HUD 2.1.0

## 多图层编辑

- **多图层选区（实验）**。用 Photoshop 套索或选框圈出区域，再移动、旋转或缩放所选像素图层的圈内内容。支持各层独立的不透明度和填充。遇到不支持的图层，命令会指出图层和原因并终止。
- **多图层液化（实验）**。在 Photoshop 原生液化窗口调整所选像素图层，可开启「显示背景」辅助对位。确认后，同一变形应用到所选图层。两项命令都在命令面板的「编辑」分组。

## 设置与录制

- 设置页精简分类并更新图标，切换标签页更流畅。「导出视频」放在导出位置旁。
- 改进录制数据损坏后的恢复和长序列导出，修复某些带有 `%` 的路径无法导出的问题。
- 改进 Photoshop 与 HUD 的启动连接和重连。文档命令会核对目标文档，防止排队时切换文档导致误操作。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。直接运行新版 Setup 即可正常更新，原有授权、设置、笔刷和录制作品会保留。安装器提示需要清理旧安装时，请使用配套的独立清理工具。
