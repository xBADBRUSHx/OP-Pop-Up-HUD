# OP Pop-Up HUD 2.0.3

## 新增

- 笔刷、橡皮、涂抹、命令和混合模式快捷面板共用一个大小设置。
- 更新前可查看本次更新内容，再选择下载并安装。

## 修复与优化

- 拾色器外的透明区域可正常点击穿透，移除旧更新按钮。
- 功能菜单适应屏幕大小，内容较多时可滚动查看。
- 正式版不再显示容易误解的内部授权期限；试用版显示试用到期时间。
- 缺失个别 Photoshop 图标时显示占位提示，不影响其他功能。
- 改善安装时对其他插件的保留，并完善问题报告。

安装前请保存作品并关闭 Photoshop。直接运行安装包即可更新，已有设置与授权保留；无需先卸载或运行清理工具。
