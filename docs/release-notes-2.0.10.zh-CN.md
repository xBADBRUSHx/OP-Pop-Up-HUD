# OP Pop-Up HUD 2.0.10

## 新增

- 快捷色轮新增「按键切换」。按一次 Q 打开，再按 Q 或 Esc 收起。默认仍是「按住显示」，可在 **设置 → 颜色拾色器 → 快捷拾色器** 切换。
- 单击 Toolbar 上的不透明度或流量圆，松开时将对应参数恢复到 **100%**。四个参数圆均支持拖动调整。
- Photoshop 的「透视变形」可分配到命令面板或 Toolbar。

## 改进

- 按住 Z，在命令槽位按 **Shift＋中键**，可直接搜索并分配工具或命令。已保存的槽位会在更新后保留。
- 设置窗口简化了标题和分类导航，并整理了账户与帮助页的布局。

## 修复

- 修复 Photoshop 状态同步短暂中断时反复弹出相同警告的问题。
- 改进暂停录制和关闭插件时的帧写入收尾，避免未完成的写入影响下一次录制。
- 安装程序可正确识别只报告主版本和次版本的 Photoshop。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。正常更新保留设置、授权、笔刷与录制作品。
