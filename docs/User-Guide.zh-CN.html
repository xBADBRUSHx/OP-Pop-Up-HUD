OP Pop-Up HUD 使用指南

适用于 Windows 64 位与 Photoshop 2024（25.1）及以上版本。安装需要 Adobe Creative Cloud Desktop。

安装

  1. 保存作品，退出 Photoshop 和 HUD，双击新版安装程序。
  2. 如果检测到 2.0.0 之前的 HUD，按提示确认迁移。安装器会备份并清理旧程序、设置和缓存，再安装新版，无需另外运行清理工具。旧快捷键、布局和槽位会重置；设备身份、购买权益和作品保留，安装后用原邮箱和激活码重新激活。正常 2.x 升级保留设置与授权。
  3. 如果检测到可识别的独立 OK-Record，默认在新版安装成功后移除旧插件；可取消勾选以保留旧版。录制项目、输出和插件数据保留。无法确认身份时会说明原因，不会自动删除。
  4. 打开 Photoshop，选择 增效工具 → OP Pop-Up HUD → OP Pop-Up HUD · 设置。首次出现启动 HUD 的权限提示时，选择允许。
  5. 在授权页面输入邮箱，激活正式版或开始试用，然后打开一份绘画文档。

安装程序默认直接双击运行，始终安装到当前 Windows 账户。管理员权限本身不会被拒绝；需要权限确认时，按提示允许，不要换用另一个 Windows 账户。迁移未完成时请按提示处理后重试；备份位于 %LOCALAPPDATA%\BADBRUSH\HUD-Migration-Backups。独立清理工具仍可用于手动维护旧版 HUD，不用于清理 2.0.0 或更高版本。

未激活时，从 增效工具 菜单打开的窗口居中显示，只提供授权页面。激活或领取试用后，设置分类、Toolbar 和绘画快捷键解锁；点击 Toolbar 的 设置，同一个窗口会在按钮上方展开。Toolbar 隐藏或没有打开文档时，仍可从增效工具菜单进入。

激活或试用

使用方式操作
已有激活码先填邮箱，再填激活码，点击 激活正式版。旧用户使用原邮箱和原激活码。
先试用只填邮箱，点击 开始试用，全部功能开放。
试用后购买或更换激活码切到 管理授权，填写邮箱和新激活码，点击 激活正式版，无需重装或先清除原授权。

首次激活和领取试用需要联网。试用从首次领取成功起连续计算 7 天，重装、清除本机激活或重复领取都不会重新计时。

开始绘画

让 Photoshop 处于前台，将指针移回画布。以下是默认快捷键，也可以在设置中修改。

操作用途
按住 Q打开光标附近的拾色器。
按住 W打开画笔预设面板；W 本身不切换当前工具。
短按 E / R选择橡皮 / 涂抹；继续按住可打开各自的预设面板。
按住 Z打开命令面板。
短按 F恢复正常笔刷混合模式；长按打开混合模式收藏。
按住 S 并水平移动调整笔刷大小。
按住 S + 鼠标右键 并水平移动调整不透明度。
按住 S + 鼠标左键 并垂直移动调整笔刷角度。

在 W、E、R、Z、F 面板中，指向需要的槽位后松开快捷键即可选择；也可以左键点击应用。指针回到面板中心再松键，可取消选择。

如需用 A／D 增减笔刷大小，可在 Photoshop 的键盘快捷键中，将原生 [／] 对应功能改绑到 A／D。

将当前笔刷存入收藏：先在 Photoshop 选好笔刷，按住 W 打开面板，在目标槽位 Shift + 中键点击。清空槽位使用 Shift + Alt + 中键点击。

Toolbar 的前景色或背景色图标支持 Alt + 左键重置前后景色、Shift + 左键调换前后景色，效果分别与 Photoshop 的 D、X 相同。双击前景色仍可打开 Photoshop 拾色器。

整理 Toolbar 和命令面板

  • 调整顺序：在 Toolbar 的工具上按住中键，拖到新位置后松开。
  • 收起工具：将工具中键拖出 Toolbar。需要恢复时，点击 … 打开收纳菜单，再把工具拖回。
  • 设置命令面板槽位：按住 Z，在目标槽位 Shift + 中键点击，选择需要的工具或命令；也可在 命令与工具栏 设置中修改。
  • 添加颜色命令：在槽位的命令列表中选择 编辑 → 重置前后景色／调换前后景色。
  • 新增 Toolbar 槽位：在 命令与工具栏 → 工具栏槽位 点击 添加工具栏槽位，保存成功后即可为新槽位选择工具或命令。
  • 切换分组：按住 Z 时按 1–3；按住 W 时按对应的 1–5，切换已启用的分组。

收纳菜单以 Photoshop 实际启用的工具为准。放在 Photoshop“附加工具”中的项目不会自动出现在这里。

录制与步骤图

  1. 先保存绘画文档，点击 Toolbar 的 设置，选择 录制与导出，确认录制保存位置、采样间隔及 分辨率。保存路径右侧的文件夹图标可选择保存目录。
  2. 点击 Toolbar 的录制按钮，正常绘画。再次点击可以暂停或继续。
  3. 需要保存关键进度时，点击 Toolbar 的保存步骤图按钮。
  4. 点击 录制保存位置 右侧的序列帧图标、步骤图图标查看对应文件夹。
  5. 结束录制时，按住 Shift + Alt，左键点击录制按钮。已有序列帧保留，再次开始会继续当前文档的时间线。
  6. 暂停或停止录制后，在下方 导出设置 确认素材来源，设置视频时长、每帧停留，再点击 导出视频。完成后点击 导出位置 右侧的文件夹图标查看视频；导出中可取消。

录制保存画布变化，不录制屏幕、鼠标和弹窗。切换到其他文档会暂停当前文档采样，切回后继续。关闭设置不会停止后台录制、计时或导出。

长路径会优先显示末尾；悬停可查看完整地址，点击路径后可选中复制。导出按钮不可用时，下方会说明原因。

分辨率 同时影响新录制帧和导出视频。修改前需停止录制；提高分辨率不会恢复已有帧中缺失的细节。

视频导出组件已随 HUD 安装，无需另外安装 FFmpeg。

录制输出使用 8 位像素；16 位源画面会转换为 8 位录制图像，原文档保持不变。暂不支持录制 32 位 HDR 文档。

在 导出设置 中导出已有录制或图片序列时，点击 选择序列帧 路径右侧的文件夹图标。要导出当前文档的录制，点击 使用当前录制，确认来源后再导出。原录制不会被自动移动或删除。需要手动删除时，先停止录制和导出；帧图片与配套数据应一起处理，重要录制请先备份。

计时器

单击计时器可开始、暂停或继续。按住鼠标左键约半秒打开控制面板，可选择绘画计时、秒表或倒计时，设置倒计时时长，并停止计时。

绘画计时达到设置的空闲时长后会自动暂停；从自动暂停状态继续绘画时恢复累计。切换计时模式会重置上一模式，等待再次单击开始。

更新

  1. 有新版本时，Toolbar 右侧显示蓝色 NEW。点击后选择 安装更新… 或 稍后提醒。
  2. 选择 稍后提醒 后，NEW 消失，重启也不会再次提示这个版本。以后可打开 设置 → 账户与帮助，点击 安装更新…。
  3. 选择 安装更新…，等待下载和校验完成。安装器提示关闭 Photoshop 时，先保存作品并退出 Photoshop，再按提示继续安装。

没有可用更新时，NEW 和设置中的版本更新区域都不显示。2.0.0 之后的正常更新保留当前设置与授权，不需要运行旧版清理工具。

2026-10-20 发布的是 2.0.1 安装器修订，插件功能不变，不会触发同版本更新提示。已安装 2.0.1 且使用正常时无需重复安装；此前安装失败时可下载修订后的安装包重试。

卸载与重装

先退出 Photoshop 和 HUD，再到 Windows 的已安装应用列表中找到 OP Pop-Up，选择卸载。正常卸载保留设置、授权数据和录制文件，方便以后重装。

同版本修复或安装后续版本，直接运行安装程序即可。不要用旧版清理工具修复或卸载 2.0.0 及以上版本。

遇到问题

打开 设置 → 账户与帮助，点击 生成问题报告。完成后点击 打开报告位置，将选中的 ZIP 发到 100209743@qq.com，简单说明问题； 如有报错截图，请一并发送。

安装前检查或迁移报错时，可选中错误说明与网址并复制（Ctrl+A 全选，Ctrl+C 复制）。缺少 Adobe 安装组件时，点击 打开 Creative Cloud 下载页，安装或修复后重试。

安装出错时，错误页面会显示 生成问题报告；正常安装页面不显示该按钮。插件打不开或安装器已退出时，可解压独立报告工具，双击 OP Pop-Up Report.exe。无需启动 Photoshop，不收集作品，不会自动发送。

报告包含可获取的安装、迁移与 Adobe 日志，以及采集报告时的权限信息，并对敏感字段脱敏。

情况处理方式
安装提示找不到 Adobe 安装组件（UPIA）安装或修复 Creative Cloud Desktop，再重新运行安装器。
Adobe 提示未登录（-631）打开 Creative Cloud Desktop 并登录，然后重试当前操作。
Adobe 权限未获批准（-629）重试当前操作，并完成出现的 Windows 或 Adobe 权限确认。
Adobe 权限提示超时（-630）检查是否有待处理的 Windows 或 Creative Cloud 权限窗口；如果没有看到提示，生成问题报告，不需要反复尝试。
找不到设置入口确认 Photoshop 为 25.1 及以上，重启 Photoshop，再检查“增效工具”菜单。
快捷键没有反应检查授权状态，让 Photoshop 处于前台，退出文字输入或弹窗，再将指针移回画布。
更新提示程序仍在运行保存作品，退出所有 Photoshop 和 HUD 窗口，按安装器提示继续；若已退出安装器，重新运行下载好的安装包。
清理工具显示“未完成”按提示处理；仍无法完成时，将提示截图发给作者核实后再安装。
提示达到设备上限联系卖家处理设备名额。清除本机激活不会释放服务器设备名额。
需要离线激活在账户页切到 离线与其他选项（已激活时为 管理授权），将机器码提供给卖家，收到授权文件后点击 导入离线授权文件。

补充说明

  • 从 2.0.0 之前的旧版升级到新版时，旧快捷键、布局和槽位配置全部重置；购买权益、设备身份和用户作品保留。之后同代更新保留新配置。
  • 授权会在联网时自动刷新。长期离线超过授权凭证有效期后，请联网打开设置；购买权益不会因为清理旧版而丢失。
  • 安装包暂未做 Windows 代码签名，首次运行可能出现系统提示。请核对下载来源和文件信息后再继续。
  • 报错时请提供提示截图、Photoshop 版本以及出问题前的操作；不要在公开截图中展示激活码。
