# OP Pop-Up HUD 2.0.7

## 新增

- 快捷面板中央图标支持 SVG 与透明 PNG，按可见内容自动居中、保持比例。PNG 保留原色与透明度，SVG 继续支持 Logo 颜色。
- W 收藏组与命令面板分组可独立设置图标大小，默认 50，可输入 1–80，并支持单组恢复默认。

## 改进

- 减少工具状态通知的重复读取，保留工具切换与命令完成的同步顺序。
- 避免 Perspective 响应较慢时阻塞工具栏显示。
- 录制扫描在内容未变化时保留现有清单，减少重复写入。

## 修复

- 修复录制监听在取消、重新初始化及 Photoshop 退出时的清理问题。
- 移除无用的步骤图恢复扫描，避免损坏步骤图阻断录制与计时器初始化，或使已保存的目录设置报错。实际步骤图写入与导出仍保留校验。
- 设置编码备份保护其引用的笔刷、橡皮擦与涂抹缩略图，避免清理后恢复备份时缺图。
- 补齐更新版本号校验，避免异常版本导致“稍后”无法保存。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。正常更新保留设置、授权、笔刷与录制作品。
