# OP Pop-Up HUD 2.0.8

## 新增

- 圆形 OKLCH 色轮可开启两侧弧条：左侧选择黑白灰度，右侧调整明度并保留色相和相对色度。两边均向上变亮、向下变暗。
- 开关位于 **设置 → 颜色拾色器 → 拾色器顺序 → 圆形 OKLCH 两侧弧条**，默认关闭，快捷与常驻拾色器共用。

## 改进

- 操作失败时显示具体工具或命令；问题报告补充拒绝原因、连接和队列状态，便于定位偶发问题。

## 修复

- 新建像素图层改用 Photoshop 原生创建动作，遵循当前选中图层的插入位置。
- 连续调明度、调色相时合并尚未发送的颜色，保留最终选择，修复输入快于 Photoshop 处理时的命令积压与提交失败。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。正常更新保留设置、授权、笔刷与录制作品。
