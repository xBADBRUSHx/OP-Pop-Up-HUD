# OP Pop-Up HUD 2.0.0 更新说明

2.0.0 启用新的安装与配置体系，并将 OK-Record 录制功能并入 HUD。

## 主要变化

- **录制一并安装**：在 HUD 中录制绘画过程、保存步骤图和导出视频，无需保留独立 OK-Record。
- **命令面板默认使用 Z**：S 保留鼠标调节笔刷大小、不透明度和角度；如需 A／D 增减大小，请在 Photoshop 中改绑原生 `[`／`]`。
- **试用 7 天**：填写邮箱即可领取全部功能试用；已有激活码可直接激活授权。
- **按需更新**：有新版本时显示 NEW。选择稍后更新后，可从插件面板继续更新。
- **延续新配置**：2.0.0 之后的正常更新保留设置与授权，不需要再运行旧版清理工具。

## 旧用户升级

1. 保存作品，退出 Photoshop 和 HUD。
2. 完整解压旧版清理工具，运行 `Start-Cleanup.cmd`，核对清单后输入大写 `CLEAN`。
3. 看到“清理完成，按任意键退出”后，运行 2.0.0 安装程序。
4. 打开插件面板，用原邮箱和原激活码重新激活。

首次安装直接运行安装程序即可。安装器检测到旧版 OK-Record 时会提示替换，已有录制文件保留。

## 补充说明

- 旧版用户需按上述步骤手动迁移至 2.0.0。
- 旧快捷键、面板布局、笔刷槽位等配置全部重置；购买权益、设备身份和用户作品保留。
- 一次性清理工具只用于 2.0.0 之前的 HUD；请勿用于卸载或修复新版。
- 录制输出为 8 位图像，16 位源画面会转换；暂不支持录制 32 位 HDR 文档，原文档保持不变。
- 本版暂未做 Windows 代码签名。请核对下载来源与文件信息。

详细操作见[使用指南](User-Guide.zh-CN.md)。
