# OP Pop-Up HUD 2.0.6

- 改善更新内容面板：统一窗口宽度、字体、行距与留白，长说明可滚动阅读，操作按钮始终可见。
- 保持“稍后”为默认操作，支持 Esc 取消；更新信息发生变化时关闭旧确认窗口。
- 修订安装器的程序运行提示：保存作品并关闭 Photoshop 和 HUD 后，点击“已关闭，继续安装”即可在当前窗口重新检查并安装。“返回”回到准备安装页，安装器不会强制关闭程序。

旧版客户端已可获取分组后的更新文案。新版窗口布局由客户端提供，安装此版本后用于后续更新提示。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。正常更新保留设置、授权、笔刷与录制作品。
