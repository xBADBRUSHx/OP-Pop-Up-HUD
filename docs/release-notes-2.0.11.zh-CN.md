# OP Pop-Up HUD 2.0.11

## 吸管取样

- Z 命令面板新增五种取样范围。可选择当前图层、所有图层、当前和下方图层，以及后两种范围各自的「忽略调整」选项。
- 当前图层、所有图层、当前和下方图层使用三款对应图标，以亮起的图层表示取样范围。
- 按住 Z，在目标槽位按 **Shift＋中键**，搜索「吸管取样」即可分配。执行时保留当前工具、取样大小和取样环设置。

安装前请保存作品并退出 Photoshop 和 OP Pop-Up HUD。正常更新保留设置、授权、笔刷与录制作品。
